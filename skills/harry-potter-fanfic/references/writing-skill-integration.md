# Complementary writing support

The included workflows support drafting, revision and continuity. Use an existing
general writing or project-specific continuity skill when it serves the request.
The host project's accepted voice, story state, language and formatting govern
the result; this skill supplies canon evidence and the seven-book reference library.

Consult the active skill list and project configuration for complementary support.
Use a companion only for a distinct need such as general prose review or serial
state management. Continue the requested writing with the built-in workflows.

If the user asks to add a companion, explain its role and the available installation
route. Installation requires the user's authorization. Do not interrupt ordinary
drafting, factual lookup or source maintenance with an installation proposal.

Canon and story-local decisions retain their own authority: the shared book
references support novel evidence, while accepted project records govern the
story's inventions and alternate-universe choices.
