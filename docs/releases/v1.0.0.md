# 1.0.0 — Seven core books

This first milestone incorporates all seven core novels into the writing
reference system. Typed retrieval now includes *Order of the Phoenix*,
*Half-Blood Prince* and *Deathly Hallows* beyond the four books in 0.4.2.

## References and tools

- All seven books use the same character, spell, place, object, evidence and
  coverage contract: 1756 per-book records across 199 chapter anchors.
- The data contains 809 characters, 181 spell families, 344 places and 422
  objects. Objects retain explicit magical, ordinary or uncertain status.
- Book-scoped glossary and category commands support PS, CoS, PoA, GoF, OotP,
  HBP and DH. `semantic --book all` searches across them; shared referent IDs
  connect identities while retaining each book's evidence and reveal limits.
- DH chapter retrieval accepts `DH-epilogue`; `DH37` is not a chapter anchor.
- HBP silent-casting evidence and edition-specific vocalisation remain
  distinct. Whispered incantations are spoken, and unnamed effects do not
  acquire guessed spell identities.
- Two focused cards cover Prince authorship and non-verbal casting evidence.
  The separate evidence-card library now has 64 entries; the selective series
  glossary remains at 192.
- DH Hungarian lookup exposes transcription and spelling limitations.
  `lint-hu --book DH` provides no spelling replacements, and other book scans
  exclude editorial labels from suggestions.
- The entrypoint is shorter and routes to the common seven-book interface.
  English remains the default output language; saved project preferences and
  explicit overrides continue to apply.

## Scope and verification

Inventory completion is separate from independent full-book semantic reading,
which remains incomplete. Counts are per-book records and grouped casting rows,
not globally unique entities or individual physical casts. Whole-book results
can reveal later information; chapter filters do not enforce viewpoint knowledge.

The [milestone review](../core-books-milestone.md) records source decisions and
the supported response to the existing blinded comparison. That comparison had
mixed intermediate preferences and no factual failures, including in bare model
drafts. It does not evaluate the new HBP/DH inventories or establish generally
better prose.

New tests were explicitly deferred for this release. No fresh writing test,
local automated-suite result or installation smoke test is claimed. Original
books and full-text research are excluded from the published skill.

## Install this version

```sh
npx skills add https://github.com/lakatos-alex/hp-writing-skill/tree/v1.0.0 --skill harry-potter-fanfic
```

Optional local tools require Node.js 22 or newer, without third-party runtime
dependencies. The skill is distributed through GitHub and the skills CLI;
there is no separate npm package.
