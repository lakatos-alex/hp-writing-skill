# 0.4.2 — Project language preferences

Reference queries now default to English. Agents can save a story project's
language once, then reuse it across calls and from subdirectories:

```sh
node /path/to/skill/scripts/hp.mjs config --lang hu --project /path/to/story
```

The preference is stored in `.hp-writing.json` in the story project. Use `en`,
`hu` or `both`. An explicit `--lang` overrides it for one call; `--project` and
`--config` support queries made from elsewhere. The skill setup process uses the
accepted project language and avoids asking for it again.

Single-language output omits counterpart headwords, labels and source locators,
plus mixed untagged aliases and search terms. English results also omit marked
Hungarian localization commentary. Retrieval still accepts bilingual queries.
Returned detail commands preserve the selected language. Explanatory summaries
remain English in Hungarian mode; the tool does not translate them.

## Compatibility

- Existing CLI consumers needing paired fields must add `--lang both` or save
  that project preference. Direct JavaScript data APIs remain bilingual.
- `align` follows the selected language. Add `--lang both` for paired chapter
  access. Import, inventory, search and read require `en` or `hu`.
- Record IDs, pagination, reference counts and coverage are unchanged: 997 typed
  records across the first four books, with seven-book chapter metadata.
- Statistics and manuscript checks do not use the preference. Hungarian lint
  remains a deliberate advisory check.

## Validation

The release passed 101 automated tests, package validation, local source checks
and an isolated installation smoke test. These checks verify configuration,
output projection and existing tool behavior. A fresh writing evaluation remains
pending; this release makes no new writing-quality claim.

## Install

```sh
npx skills add https://github.com/lakatos-alex/hp-writing-skill/tree/v0.4.2 --skill harry-potter-fanfic
```

Optional tools require Node.js 22 or newer. Guidance has no runtime requirement.
