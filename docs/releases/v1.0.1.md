# 1.0.1 — Unified canon reference

This patch brings selected knowledge from the shared evidence database into a
compact manual reference and makes the integrated seven-book experience easier
to use while drafting.

## What changed

- One readable guide of 20 canon constraints across all seven novels, generated
  from the same fact database used by the optional tool.
- 72 evidence cards, including eight additions on object scope, injuries, supplies,
  refuge risk and when characters learn consequential mechanisms.
- Unified `glossary --book all` lookup and safe `facts --book BOOK` projections
  for all seven novels, preserving source and knowledge limits.
- Cross-book suggestions after an empty scoped entity search, with original
  attribution and an explicit prompt to inspect evidence before use.
- Equal direct manual navigation for every book's characters, spells, places,
  objects and coverage.
- A smoother drafting path: included workflows work independently; tools,
  language configuration and complementary writing support are optional.
- Windows frontmatter compatibility and automated checks for the generated
  reference, safe projections and retrieval scope.

The seven-book typed library remains 1756 per-book records and 199 chapter anchors.
English and Hungarian terminology, evidence contracts, referent identities and
scene-knowledge limits remain part of the same writing experience.

## Writing comparison

A fresh Luna Medium writer used the same prompt as the previous skill-only run.
A blinded Sol 6.1 Medium judge rated the expanded-reference draft **16/20** against
the earlier draft's **13/20**, with the gain in canon accuracy, and preferred the
expanded-reference draft. This is a targeted observation, not a calibrated
percentage of literary quality.

## Install

```sh
npx skills add https://github.com/lakatos-alex/hp-writing-skill/tree/v1.0.1 --skill harry-potter-fanfic
```

The guidance and manual references have no runtime requirement. Optional tools
require Node.js 22 or newer and have no third-party runtime dependencies. Existing
project language settings and script interfaces remain supported.

## Validation

The release passes 109 automated tests, seven-book source and inventory checks,
package validation and a fresh installation smoke test. The installed files are
checked against the release package, including unified lookup, Hungarian chapter
references and optional bounded primary-source access.
