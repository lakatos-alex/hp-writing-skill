# Optional local sources

Place your own accessible book copies here only if useful, or keep using your project's existing source location. No filenames or moves are required. An optional local `books.md` can identify titles, editions, languages and paths. Add only material you are entitled to use.

Everything here except this README is ignored by Git; the directory is excluded from `git archive`. Do not force-add books, extracted passages or private notes. Git ignore rules do not control other editors, cloud sync or agent access.

Follow the [bounded source-access guide](../skills/harry-potter-fanfic/references/local-sources.md) when checking a concrete fact. The skill works without books. TXT and Markdown can be searched directly; EPUB and PDF need an existing reader. No book text, download service or conversion pipeline is supplied.
